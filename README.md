## Latest projects

### 🌃 [NEON//ASCII](https://github.com/zainkhalid91/Cyberpunk-ASCII-World-)
A playable, rainy cyberpunk side-scroller rendered as live ASCII art. One runtime shader turns each cell into a glyph by brightness. Compose Multiplatform, for Windows and Android.

<a href="https://github.com/zainkhalid91/Cyberpunk-ASCII-World-"><img src="https://raw.githubusercontent.com/zainkhalid91/Cyberpunk-ASCII-World-/main/docs/screenshots/01-ascii.png" width="720" alt="NEON//ASCII in ASCII mode" /></a>

### 🧱 [Brick Breaker Retro](https://github.com/zainkhalid91/brick-breaker-compose)
An arcade brick breaker with 10 levels, 10 worlds and 4 boss fights. No images, sprite sheets or game engine: every brick, ball and boss is painted in Kotlin on a Compose `Canvas`, with zero allocations per frame.

<a href="https://github.com/zainkhalid91/brick-breaker-compose"><img src="https://raw.githubusercontent.com/zainkhalid91/brick-breaker-compose/main/docs/all-levels.jpg" width="720" alt="All ten levels of Brick Breaker Retro" /></a>

[Download the APK](https://github.com/zainkhalid91/brick-breaker-compose/releases/latest/download/BrickBreaker.apk)

### 🕌 Salah, for [Android](https://github.com/zainkhalid91/salah-android) and [Windows](https://github.com/zainkhalid91/salah-windows-)
Prayer times with a dot matrix clock, reminders with the azan, a Hijri calendar, sunnah times, a Qibla compass and home screen widgets. In English and Arabic. Both apps share the same prayer calculation code, so they agree to the minute.
